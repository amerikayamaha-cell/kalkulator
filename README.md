# Kalkulator

Aplikasi kalkulator sederhana berbasis web.

## Fitur

- Operasi tambah, kurang, kali, dan bagi
- Persentase dan tanda positif/negatif
- Tombol hapus dan penghapusan seluruh input
- Dukungan keyboard
- Tampilan responsif

## Menjalankan

Buka `index.html` langsung di browser atau aktifkan GitHub Pages melalui menu **Settings → Pages**.
